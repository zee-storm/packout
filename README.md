# PackOut

A market day, start to finish, on the seller's phone.

Sellers count what goes into the cooler, log what happened at the booth, and
count what's left at close. The owner sees every market from one screen.

**This is a prototype.** Every flavour, price, market and person in it is
invented placeholder data. There is no server yet — everything is kept in the
one phone's own storage.

Open it: https://zee-storm.github.io/packout/

On a phone, use your browser's **Add to Home Screen** to install it. It then
opens full screen, with no address bar, and still opens with no signal.
